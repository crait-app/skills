Overview

Telegram 生态开发技能

全面的 Telegram 开发指南，涵盖 Bot 开发、Mini Apps (Web Apps)、客户端开发的完整技术栈。

何时使用此技能

当需要以下帮助时使用此技能：

  • 开发 Telegram Bot（消息机器人）
  • 创建 Telegram Mini Apps（小程序）
  • 构建自定义 Telegram 客户端
  • 集成 Telegram 支付和业务功能
  • 实现 Webhook 和长轮询
  • 使用 Telegram 认证和存储
  • 处理消息、媒体和文件
  • 实现内联模式和键盘

Telegram 开发生态概览

三大核心 API

  1. Bot API - 创建机器人程序

    • HTTP 接口，简单易用
    • 自动处理加密和通信
    • 适合：聊天机器人、自动化工具

  2. Mini Apps API (Web Apps) - 创建 Web 应用

    • JavaScript 接口
    • 在 Telegram 内运行
    • 适合：小程序、游戏、电商

  3. Telegram API & TDLib - 创建客户端

    • 完整的 Telegram 协议实现
    • 支持所有平台
    • 适合：自定义客户端、企业应用

Bot API 开发

快速开始

API 端点：

https://api.telegram.org/bot<TOKEN>/METHOD_NAME

获取 Bot Token：

  1. 与 @BotFather 对话
  2. 发送 /newbot
  3. 按提示设置名称
  4. 获取 token

第一个 Bot (Python)：

 1import requests
 2
 3BOT_TOKEN = "your_bot_token_here"
 4API_URL = f"https://api.telegram.org/bot{BOT_TOKEN}"
 5
 6# 发送消息
 7def send_message(chat_id, text):
 8    url = f"{API_URL}/sendMessage"
 9    data = {"chat_id": chat_id, "text": text}
10    return requests.post(url, json=data)
11
12# 获取更新（长轮询）
13def get_updates(offset=None):
14    url = f"{API_URL}/getUpdates"
15    params = {"offset": offset, "timeout": 30}
16    return requests.get(url, params=params).json()
17
18# 主循环
19offset = None
20while True:
21    updates = get_updates(offset)
22    for update in updates.get("result", []):
23        chat_id = update["message"]["chat"]["id"]
24        text = update["message"]["text"]
25        
26        # 回复消息
27        send_message(chat_id, f"你说了：{text}")
28        
29        offset = update["update_id"] + 1

核心 API 方法

更新管理：

  • getUpdates - 长轮询获取更新
  • setWebhook - 设置 Webhook
  • deleteWebhook - 删除 Webhook
  • getWebhookInfo - 查询 Webhook 状态

消息操作：

  • sendMessage - 发送文本消息
  • sendPhoto / sendVideo / sendDocument - 发送媒体
  • sendAudio / sendVoice - 发送音频
  • sendLocation / sendVenue - 发送位置
  • editMessageText - 编辑消息
  • deleteMessage - 删除消息
  • forwardMessage / copyMessage - 转发/复制消息

交互元素：

  • sendPoll - 发送投票（最多 12 个选项）
  • 内联键盘 (InlineKeyboardMarkup)
  • 回复键盘 (ReplyKeyboardMarkup)
  • answerCallbackQuery - 响应回调查询

文件操作：

  • getFile - 获取文件信息
  • downloadFile - 下载文件
  • 支持最大 2GB 文件（本地 Bot API 模式）

支付功能：

  • sendInvoice - 发送发票
  • answerPreCheckoutQuery - 处理支付
  • Telegram Stars 支付（最高 10,000 Stars）

数据验证

服务器端验证 initData (Python)：

 1import hmac
 2import hashlib
 3from urllib.parse import parse_qs
 4
 5def validate_init_data(init_data, bot_token):
 6    # 解析数据
 7    parsed = parse_qs(init_data)
 8    received_hash = parsed.get('hash', [''])[0]
 9    
10    # 移除 hash
11    data_check_arr = []
12    for key, value in parsed.items():
13        if key != 'hash':
14            data_check_arr.append(f"{key}={value[0]}")
15    
16    # 排序
17    data_check_arr.sort()
18    data_check_string = '\n'.join(data_check_arr)
19    
20    # 计算密钥
21    secret_key = hmac.new(
22        b"WebAppData",
23        bot_token.encode(),
24        hashlib.sha256
25    ).digest()
26    
27    # 计算哈希
28    calculated_hash = hmac.new(
29        secret_key,
30        data_check_string.encode(),
31        hashlib.sha256
32    ).hexdigest()
33    
34    return calculated_hash == received_hash

最佳实践

Bot 开发

  1. 错误处理

    1try:
2    response = requests.post(url, json=data, timeout=10)
3    response.raise_for_status()
4except requests.exceptions.RequestException as e:
5    print(f"请求失败: {e}")

  2. 速率限制

    • 群组消息：最多 20 条/分钟
    • 私聊消息：最多 30 条/秒
    • 全局限制：避免过于频繁

  3. 使用 Webhook 而非长轮询

    • 更高效
    • 更低延迟
    • 更好的可扩展性

  4. 数据验证

    • 始终验证 initData
    • 不要信任客户端数据
    • 服务器端验证所有操作
